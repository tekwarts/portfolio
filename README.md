# Eddie Li - Software Engineering Portfolio

A modern, high-performance portfolio website built with **React**, **Vite**, and **Tailwind CSS** to showcase Eddie Li's experience as a Senior Software Engineer specializing in Distributed Systems, Event-Driven Architecture, Cloud, and AI Systems.

## Features

- **Hero & Identity**: Highlights verified Canadian Permanent Resident status (no sponsorship required), bilingual C1 proficiency (English & French), direct contact buttons, and key performance impact benchmarks (+40% Kafka Throughput, -35% Search Latency).
- **Interactive Experience Timeline**: Covers all 3 career roles at **Ruiting Tech** (Senior SWE, SWE II, SWE I) with role-based filtering, instant keyword search, and detailed technical accomplishments.
- **System Architecture Showcase**: Interactive tabbed deep-dive into:
  1. *Event-Driven Reservation & Leasing Engine* (Kafka, Transactional Outbox, DLQ)
  2. *High-Volume Multi-Dimensional Property Search* (Elasticsearch, MongoDB, Kafka Sync, Redis)
  3. *AI Property Summarization & RAG Microservice* (Python, FastAPI, pgvector, LLM APIs)
- **Comprehensive Skills Matrix**: Grouped by Programming Languages, AI & LLMs, Backend & Frameworks, Cloud & DevOps, Databases & Storage, and Microservices & Distributed Systems with search & category filters.
- **Education & Credentials**: Shanghai University (B.Eng in Information Engineering), language certificates, and work eligibility.
- **ATS / Print-Ready Resume Modal**: Matches the exact 1-page paper layout with one-click **Print / Save as PDF** and **Copy Text** functionality.
- **Theme Support**: Seamless Dark Mode / Light Mode with automatic system preference detection and localStorage persistence.

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
Generates optimized static assets in the `dist/` directory.

### 4. Preview Production Build
```bash
npm run preview
```
